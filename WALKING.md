# Прогулки без ключей и платёжных данных

В «Места → Прогулки» создайте прогулку минимум с двумя точками (или домом и местом). В «Маршрут и активность» нажмите «Пеший маршрут и высоты».

- Карты: существующий Leaflet 1.9.4 и слои Esri — схема, спутник, спутник с подписями, рельеф. BRouter не поставляет изображения карты.
- Маршруты: публичный BRouter https://brouter.de/brouter, профиль `hiking-mountain`, данные OpenStreetMap. Ключ, аккаунт и платёжный способ не требуются. Публичный сервер может быть недоступен или ограничить запросы. Запросы выполняются только по кнопке, без автоматических повторов, с тайм-аутом 25 секунд.
- По нажатию сервис получает координаты точек, включая дом, если он включён в маршрут. Вес, имя, рост и активность в запрос не отправляются. Геолокация автоматически не запрашивается.
- Длина считается по дорожной линии. Подъём/спуск — из высот координат с порогом 3 м для подавления шума. Профиль отображается равномерно по расстоянию. При отсутствии хотя бы одной высоты рельеф отмечается как неизвестный, без выдуманных нулей.
- Прогноз времени: расстояние / скорость из настроек + 1 мин на каждые 10 м подъёма. Паузы на местах показываются отдельно. Для крутых спусков, погоды, покрытия и усталости отдельной модели нет. Маршрут не гарантирует проходимость и актуальность троп, особенно на горных участках.
- Шаги — расстояние / личная длина шага. По умолчанию рост × 0,413 или условные 70 см. Активные ккал — оценка по MET, весу и времени движения с грубой энергетической поправкой на подъём. Это оценки, не данные датчика. Без веса калории не рассчитываются.
- После прогулки уточните фактические данные и нажмите «Я прошёл — в активность». Своя запись появится в «Тело → Активность». За одну прогулку и дату повторное сохранение обновляет свою запись без дубля. За партнёра активность не создаётся; чужие записи только для просмотра.
- Коллекция ARR.activity зарегистрирована для существующей синхронизации. Геометрия и массив высот живут только в открытом диалоге, в S сохраняется сводка активности. Старые записи Google сохранены с указанием прежнего источника; SDK, форма ключа и запросы Google удалены.
- При сетевой ошибке можно заполнить поля вручную. Прямая × 1,3 до расчёта явно обозначена как приблизительная оценка.

Проверки: `node tests/walking.test.cjs` (без npm). Разбор GeoJSON, отсутствие высот, неверные координаты, собственные записи, дубли, смена пользователя, пеший профиль без ключа, сетевая ошибка и закрытие формы во время запроса.

В браузере на 390 px проверены реальный запрос BRouter «Парк Ваке → Черепашье озеро», линия маршрута, высоты, переключение спутника с подписями и сохранение активности. Результат тестового маршрута: около 1,4 км, +167/-6 м, 37 минут при скорости 4,5 км/ч; данные карты могут обновляться.

Основная карта: выбранная прогулка автоматически строится по дорожной сети. До ответа сервиса и при ошибке прямая линия не рисуется. Результат кэшируется в памяти по координатам и скорости и используется в карточке и диалоге активности; при ошибке есть кнопка повторного запроса. Линия — синий пунктир с тонкой белой обводкой.
